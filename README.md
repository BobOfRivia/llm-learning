# LLM 技术演进知识体系

梳理 2020 年至今大语言模型领域的完整发展图景：架构演进、训练范式变迁、scaling 规律、竞争格局。

## 结构

- **tracks/**：技术轨道（架构、训练、scaling、数据、推理优化、对齐）
- **capabilities/**：能力输出索引，桥接 Agent 工程项目
- **labs/**：各实验室的路线差异与关键决策
- **eras/**：范式纪元（Scaling → Alignment → 能力竞赛 → 推理）
- **topics/**：关键概念深度展开
- **logs/**：范式替代日志、待归位新进展、开放问题

## 姊妹项目

`../learning/` — Agent 工程知识体系。两个项目通过 capabilities/ ↔ dimensions/ 自然连接。
