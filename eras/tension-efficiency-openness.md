# 效率与开放（贯穿性张力）

## 为什么不是一个"纪元"

效率优化和开源/开放不构成一个独立的时间段，因为它们没有自己的主导叙事——它们是*对其他纪元的响应机制*。每当一个新的能力前沿被建立（scaling → alignment → 多模态 → reasoning），它总是首先以昂贵、封闭、需要专业硬件的形态出现。效率张力的任务是降低这个成本，开放张力的任务是让这个能力可以被更多人获取。两条线不定义纪元，而是跟随并改造每个纪元。

这个结构之所以值得独立成文，是因为它揭示了一个元规律：LLM 技术的扩散不只靠前沿研究，还靠一个看不见的"民主化飞轮"——研究前沿建立能力，工程将其压缩，开源将其传播，社区将其应用。缺少这个飞轮，GPT-3 的 175B 模型今天仍然会是只有少数人能访问的研究玩具。

## 效率张力的结构

效率张力在每个纪元的表现是具体的，但背后有同一个结构：**新能力前沿建立 → 成本高到无法商业化 → 工程在 1-2 年内降低 1-2 个数量级 → 打开新的应用空间**。

**Scaling 纪元的效率问题是内存和硬件门槛。** GPT-3（175B）在 FP32 精度下需要约 700GB 显存，只有拥有大型 GPU 集群的组织才能运行推理。量化是突破这个门槛的关键工程路线：GPTQ（2022 年，arXiv 2210.17323）首次让 LLM 的 INT4 量化在质量损失可控的前提下可用，65B 模型可以在 4 张 RTX 3090 上推理；AWQ（2023 年）进一步改进，只需要保护约 1% 的"显著权重"就能维持大部分质量；GGUF 格式（llama.cpp 项目）将这套工具链推向 CPU 和笔记本——到 2023 年底，Llama 2 7B 已经可以在普通笔记本上每秒生成 10-20 个 token。从"700GB 集群"到"笔记本可用"，用了约两年。

**Alignment 纪元的效率问题是训练流程复杂度。** RLHF 三阶段流水线（SFT → RM → PPO）需要同时维护四个模型，PPO 超参数敏感，奖励 hacking 风险高，工程实现门槛极高。DPO（2023 年，arXiv 2305.18290）用数学推导证明这三阶段可以压缩为一个分类损失，直接在偏好对上训练，不需要 reward model 和 PPO 采样。它不改变对齐的本质目标，只是大幅降低了工程门槛——发布后迅速成为开源社区首选，此后涌现的 KTO、ORPO、IPO 等变体延续了同一方向：在不牺牲对齐质量的前提下，让训练流程更简单、更稳定。

**能力竞赛纪元的效率问题是长上下文和高并发 serving 的成本。** Transformer 的注意力机制复杂度是序列长度的平方，长上下文在训练和推理时都昂贵；高并发服务场景下，KV Cache 的内存碎片化严重限制吞吐量。Flash Attention（Dao et al., 2022，arXiv 2205.14135）通过 IO-aware 重新设计，将注意力计算从"反复读写 HBM"改为"分块在 SRAM 内计算"，实现 2-4x 训练加速、5-20x 内存降低——这是长上下文扩展的工程基础，没有 Flash Attention，百万 token 上下文不可能落地。vLLM（UC Berkeley，2023 年，arXiv 2309.06180）通过 PagedAttention 把操作系统的虚拟内存思想用于 KV Cache 管理，叠加连续批处理，使服务吞吐量比朴素实现高 24 倍，成为开源 LLM serving 的事实标准。

**推理纪元的效率问题是 inference-time compute 带来的结构性成本压力。** 思维链 token 的成本可以是普通 token 的 10-100 倍，且每次请求的计算量不可预测，传统 serving 框架的调度假设全部失效。这个阶段的效率创新更分散：推测解码（Leviathan et al., 2023）让串行生成在代码等重复性任务上实现 2-5x 加速；PD 分离（Prefill/Decode 解耦部署）使长上下文和高并发请求下的硬件利用率显著提升；DeepSeek 的 MLA 架构将 KV Cache 内存压缩 87%，从架构层面彻底改变了显存使用的结构。

## 开放张力的演进

开放张力的主线是**开放权重模型与同时期最强闭源模型之间的能力差距如何随时间变化**。这个差距不是单调收敛的，而是按能力维度分化：某些维度追赶很快，某些维度至今仍有代差。

2023 年初，差距是巨大且全面的。Llama 1（2023 年 2 月）65B 才勉强追上 GPT-3.5 水平，而 GPT-4 已经在多数任务上遥遥领先。这个时期开源生态的贡献不在于缩小能力差距，而在于验证了"开放权重 + 指令微调"是可行路线：Stanford Alpaca 用 500 美元的 GPT-3.5 生成数据微调 Llama 7B，产出有竞争力的聊天模型，证明合成数据指令微调的可行性；Llama 2（2023 年 7 月）附带商业许可证，是 Meta 的战略升级，这次开放是有意图的，不是泄露的结果。

2023 年底到 2024 年，差距在语言任务上显著缩小。Mistral 7B（2023 年 9 月）超过 Llama 2 13B，证明数据效率和架构调优可以在更小参数量上取得更好效果；Mixtral 8x7B（2023 年 12 月）是第一个生产级开源 MoE 模型，以 13B 的推理成本打出 70B dense 的能力——这是 MoE 架构可用性在开源生态的首次验证。Llama 3（2024 年 4 月）把过训练策略推向极端，8B 模型超过 Llama 2 70B；Llama 3.1 405B（2024 年 7 月）是第一个开放权重的前沿级大模型，在综合基准上进入与 GPT-4o 竞争的范围。

2025 年，差距在推理能力维度首次实质性消失。DeepSeek-R1（2025 年 1 月，arXiv 2501.12948）在 AIME 2024 和 MATH-500 上与 o1 持平或超过，同步开放权重和详细技术报告——这是第一次，开放权重模型在某个重要能力维度上与 OpenAI 最新前沿模型在同一档位。这个事件的意义在于打破了一个假设：推理能力的复现需要 OpenAI 规模的私有思维链标注数据。R1-Zero 实验证明，只需可验证奖励信号，推理策略可以从 RL 中自然涌现。

但差距不是均匀消失的。截至 2026 年，在多模态生成、音频理解、视频理解等能力维度，开放模型与闭源前沿仍有明显差距；训练数据的透明度（即便权重开放，数据集也通常不开放）是一条持续的分界线。

## 两条张力的相互强化

效率张力和开放张力不是独立的两条线，它们互相依赖、互相加速。

开放权重是效率研究的前提。量化、蒸馏、LoRA 微调——这些效率技术的本质是"对模型的内部结构做工程改造"，没有权重访问权限就无法进行。闭源模型可以提供 API，但无法被量化为 INT4 在本地运行，无法被 QLoRA 微调在私有数据上适配。开源生态几乎所有效率基础设施（llama.cpp、GPTQ、vLLM、LoRA 实现）都是基于开放权重模型构建的，然后反向影响了整个领域对效率优化的理解。

反过来，效率优化是开放权重真正实现"可及"的条件。一个需要 8 张 A100 才能运行的 70B 开放权重模型，对 99% 的潜在用户仍然是封闭的。正是量化、蒸馏和边缘推理工具链，使得"开放权重"从"研究人员可以下载"转变为"任何人都可以部署"。没有效率基础设施，开放权重只是一个符号性开放。

DeepSeek 是这种相互强化最典型的案例。芯片出口管制（无法获得 H100）迫使 DeepSeek 在架构层面深度优化：MLA（V2，2024 年）将 KV Cache 压缩 87%，不是工程 patch，而是对注意力机制存储结构的根本性重设计；FP8 全程训练（V3，2024 年）在受限精度下训出了与 GPT-4o 相当的模型。这些技术在 DeepSeek 开放技术报告后，被开源社区研究、复现，并反向影响了 Google、Meta 等拥有充足 H100 的实验室的架构选择——约束逼出的创新，通过开放扩散回了整个领域。

## 关键分歧与未决问题

**"开放"的边界在哪里？** 当前开放权重运动实际上只开放了"权重"这一层——训练数据、后训练偏好数据、RLHF 奖励模型通常仍然封闭。这意味着"开放模型"在实践中无法被完全复现：没有训练数据，无法验证权重的真实来源；没有后训练数据，无法理解对齐决策。这个不完整的开放是否足够？还是说真正的"开放"需要像真正的开源软件一样，包括完整的"源代码"（数据 + 训练流程）？当前没有共识，而这个问题的答案决定了开源生态的长期可复现性。

**效率-能力的循环会持续吗？** 历史上，每次能力跃升的效率追赶大约用了 1-2 年。但如果下一个前沿是"消耗万亿 tokens 的持续推理系统"或"完整的多模态世界模型"，追赶周期会更长还是同样被压缩？硬件创新（专用 AI 芯片、存储器带宽）和算法创新的速度是否足以持续跟上能力增长？

**开放的商业逻辑能否持续？** 目前开放权重的主要来源依赖三种不同商业动机：Meta（AI 能力内部消化，开源是生态投资）、DeepSeek（量化基金支撑，不靠 API 盈利，开源为声誉）、Mistral（开源为商誉，卖企业服务）。这些动机都是可持续的，但都不是"开源软件"意义上的规范性承诺。如果 Meta 的内部战略转向，或 DeepSeek 的母公司策略调整，开放权重的供给可能迅速收缩。开源 LLM 生态目前没有 Linux 那样的基金会治理结构，其开放性依赖于少数商业主体的持续意愿。
