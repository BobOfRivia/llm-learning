# 效率与开放（贯穿性张力）

## 为什么不是一个"纪元"

效率优化和开源/开放不构成一个独立的时间段，而是贯穿所有纪元的持续张力。每当一个新能力范式出现（scaling → alignment → 多模态 → reasoning），效率和开放社区都会在 6-12 个月内追上，形成"前沿探索 → 民主化"的循环。

## 效率张力

每个纪元都有自己的效率问题：

- **Scaling 纪元**：模型太大跑不起 → 量化、蒸馏开始
- **Alignment 纪元**：RLHF 太复杂 → DPO 简化流程
- **能力竞赛纪元**：长上下文推理成本高 → Flash Attention、PagedAttention
- **推理纪元**：inference-time compute 很贵 → 推测解码、小推理模型

## 开放张力

- Llama 系列证明开放权重可以有竞争力
- 开源社区的关键贡献不是训练新模型，而是**让模型可用**：LoRA、GGUF、vLLM
- 开源和闭源的能力差距随时间变化：某些纪元缩小，某些纪元扩大
- DeepSeek-R1 是一个标志性事件：推理模型这样的前沿能力也能被开源复现
