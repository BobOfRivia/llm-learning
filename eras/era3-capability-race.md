# 能力竞赛纪元（2023-2024）

## 主导叙事

"全面对标人类。" 对齐问题基本解决后（至少在产品层面），竞争回到能力维度——但不再是单纯的规模竞赛，而是多维度能力的全面扩展：多模态、长上下文、工具使用、代码生成。各家实验室进入激烈的产品和能力竞赛。

## 范式替代

**建立的范式**：
- 多模态成为模型标配（不再是加分项）
- 长上下文（100K+）成为竞争维度
- 工具使用 / function calling 成为原生能力
- 开源 vs 闭源双轨竞争格局形成

**开始被质疑的**：
- 纯粹的预训练 scaling 是否撞墙（"scaling wall" 讨论开始）
- benchmark 饱和——传统 benchmark 不再能区分顶级模型

## 遗产

这个纪元让 LLM 从"文本助手"变成了"全能接口"。多模态、长上下文、工具使用不再是独立的研究方向，而是产品的基本规格。开源生态在这个纪元真正成熟，Llama 和 Mixtral 证明开放权重模型可以有竞争力。
