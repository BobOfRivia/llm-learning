# 数据工程

## 一句话定义

这条轨道覆盖"用什么数据训练 LLM"——从数据来源、处理、质量控制到合成数据，追踪数据作为 LLM 关键生产要素的演进。

## 演进脉络

### 阶段 1：Web 规模爬取（2018-2021）

<!-- Common Crawl 为代表的大规模 Web 数据。
     The Pile (EleutherAI) 尝试多样化数据源。
     这个阶段的核心假设：数据量 > 数据质量。 -->

### 阶段 2：质量觉醒（2022-2023）

<!-- Chinchilla 论文让数据量的重要性被重新认识。
     数据质量开始被系统性关注：去重、过滤、分类。
     教科书级数据的价值被发现（Phi 系列）。
     数据混合比例（代码、数学、科学、对话）成为关键决策。 -->

### 阶段 3：合成数据崛起（2023-2024）

<!-- 用强模型生成训练数据给弱模型。
     Self-Instruct、Evol-Instruct 等方法。
     合成数据在后训练（SFT、偏好数据）中大规模应用。
     质量问题：model collapse 的风险——用模型输出训练模型是否会退化？ -->

### 阶段 4：数据墙与突围（2024-至今）

<!-- "数据墙"问题：高质量自然文本数据可能已接近耗尽。
     应对策略：合成数据规模化、多模态数据（视频/音频转文本）、
     领域专有数据的获取。
     数据版权争议对数据获取的影响。 -->
